## 1. HERO SECTIONS

### Current Pattern (all 5 pages)
Every hero follows the same overloaded structure:
```
Eyebrow tag
  ↓
H1 headline (2–3 lines)
  ↓
Body paragraph 1 (25–40 words)
  ↓
Body paragraph 2 (15–25 words)    ← unnecessary
  ↓
CTA buttons
```

### Target Pattern
```
Eyebrow tag
  ↓
H1 headline (2–3 lines)
  ↓
ONE line (max 20 words)
  ↓
CTA buttons
```

## 4. GLOBAL RULES FOR THE REWRITE

1. **Max 1 body paragraph per hero.** Max 20 words.
2. **No section should have more than 2 body paragraphs** outside of social proof quotes.
3. **"AI didn't create the problem" appears on max 2 pages** (Home, Codify).
4. **Card descriptions: max 20 words.** If you need more, the card is doing too much.
5. **Every section header: H2 + 1 line subtitle max.** No additional context paragraphs below subtitles.
6. **Avoid sentences that explain what the section is about** ("In this section you'll see..."). Just show it.
